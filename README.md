# Programa Institucional de Iniciação Científica (PIIC) - PYTHON
## Mini Curso de Python
Nesse mini curso você ira aprender sobre os softwares Python, Process e a aprendizagem acerca da criptografia, números de Fibonacci, divisibilidade dos inteiros e teoria das congruências. Baseando-nos na ideia de que “A melhor maneira de se aprender programação é na prática”, esta pesquisa foi baseada no estudo da teoria e na aplicação da prática do livro de Farrell (2019).

Pode ser acessado através do link: https://python.iasminmarques.com.br
